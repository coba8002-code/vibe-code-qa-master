간편 프로젝트 검수

GitHub 주소를 붙여넣거나 PC에서 프로젝트 폴더를 선택하세요. 코드는 실행하지 않습니다.

검수 결과가 이곳에 표시됩니다.

실행 · CPU/RAM · 장시간 테스트

Windows 프로그램에서 실행 검사용 폴더 승인을 먼저 클릭하세요. Docker Desktop과 로컬 테스트 이미지가 필요합니다. 네트워크 없는 컨테이너에서 테스트를 실행합니다.

기능 테스트 최대 60초, 반복 테스트 60초 (최대 허용 600초). CPU·RAM 최고값을 함께 수집합니다. Docker 외부의 실제 운영 서버에는 부하를 가하지 않습니다.

아직 실행한 테스트 없음

TEST 서버 HTTP 부하 검사

직접 실행한 로컬 TEST 서버만 대상입니다. GET 요청 최대 100회, 동시 요청 4개 제한. 서버를 먼저 실행하고 주소를 입력하세요.

아직 부하 테스트 없음

검수 보고서

실제 실행한 검사와 미검증 항목을 구분해 JSON 보고서를 내려받습니다. 이 파일만으로 운영 배포가 승인되지는 않습니다.
